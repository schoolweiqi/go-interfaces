Вход в OGS

Безопасный вход через официальный OAuth OGS. Пароль OGS это приложение не получает.

Приложение настроено на постоянный Client ID и адрес GitHub Pages.

Для OAuth страницу нужно открыть через http:// или https://, не как file://.

Поиск соперника OGS

Система времени: бёёми
OGS назначит конкретное основное время, длительность периода и число периодов после создания партии.
Войдите в OGS для автоматического поиска. Локальная доска доступна всегда.

Тонкие связи

Параметры используются только в режиме «лица». sigma вводится как доля шага доски, а threshold задаёт толщину и заметность связи.

Ход наискосок → тонкая связь 5
Прыжок через перекрёсток → тонкая связь 3
Кейма → диагональная тонкая связь 3
Прыжок через два перекрёстка → тонкая связь 1
Огейма → диагональная тонкая связь 1
